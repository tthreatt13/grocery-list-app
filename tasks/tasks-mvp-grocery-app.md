# Task List: MVP Grocery App for Busy Parents

## Feature Overview
Build a web application (React + Next.js frontend, Python backend) that helps busy parents create weekly grocery lists, manage pantry inventory, plan meals, and share lists with household members.

## Target User
Busy parents who need to efficiently plan weekly meals and manage grocery shopping for their family.
